# 部門共享大腦提案短片：第三版分鏡（38 秒，20 小節）

正本是計畫 `~/.claude/plans/proposal-zippy-thunder.md` 的「第三版」一節。第三版以新的 composition 實作（`data/cues-v3.json`、`app/src/scenes-v3/`），105 秒版與 final-v2 不動。

## 節拍基準

- 配樂：Mixkit 720「New Bass 01」（Lily J），Eric 於 2026-10-01 選定。實測 126.02 BPM，一拍 0.476 秒、一小節 1.9045 秒（`data/music-analysis.json` 的 `selected` 曲目）。
- 取曲目 13.413 秒起的 20 小節（到 51.503 秒），片長 38.09 秒。片中第 0 秒是強拍。
- drop 在片中 9.52 秒（第 6 小節第 1 拍，量到的峰值 9.517 秒）；第 5 小節第 4 拍有一個低頻弱起拍，drop 之後低頻從 −39 dB 跳到 0 dB。
- 下表的時間都是片中秒數，小節 n 從 (n − 1) × 1.9045 秒開始，四捨五入到 0.01 秒。

## 敘事與 drop

順序沿用 open → copies → meanings → halfway → converge → schedule → dogfood → outro。

- drop 前 5 小節是「問題」：開場標題、同一份規範寫了 5 次、同一個欄位 4 種意思。音樂只有中高頻，畫面安靜。
- drop 落在 halfway 的「好消息，我們已經走了一半。」：全片從問題轉向答案的那一句，也是最有力的轉折。
- drop 之後 15 小節是「答案」：收攏成 dept-brain、時程與停損、先用在自己身上，最後收回光點。
- 小節比 634 版短 5%，drop 前的三張 plate 改成 1.5 小節、1.5 小節、2 小節；開場標題讓出時間（可讀 2.56 秒，門檻 2.2 秒），copies 與 meanings 的主句剛好越過 2.8 秒的門檻。

## 視覺語言

- **單一運鏡語言**：每個鏡頭只做一件事，緩慢推近（縮放 1.00 到 1.03，線性，全鏡頭等速，不停頓、不回彈）。不搖鏡、不旋轉鏡頭、不做手持晃動。
- **轉場只用四種**：遮罩顯現、匹配剪接、倒影、克制模糊（跟焦，模糊半徑不超過 8 px，時長不超過 0.5 秒）。
- **剪接點**：每個剪接落在強拍（第 1 或第 3 拍）；每個鏡頭 2 到 4 秒。
- **文字**：每張 plate 只留一句主句，另可有一個標籤（dept-brain、W0、W8、DOGFOODING）。文字只取自 `data/cues.json`，可刪減不可改寫。進場沿用 `outExpo` 0.8 秒上移 18 px 加淡入；時間欄的結束點若等於剪接點，文字隨剪接離場；否則退場淡出 0.45 秒，在下一個剪接前完成。
- **禁止**：衝擊波、粒子、RGB 分離、鏡頭光斑、霓虹光暈、閃爍背景、彈跳緩動、假 UI 卡片。配色、字體與排版規則沿用 `docs/TREATMENT.md`（青綠 signal 是唯一強調色）。
- **留白**：9.07 到 9.52 秒畫面只剩一條青綠線，接 drop。

## 混音

- 音樂取曲目 13.413 到 51.503 秒；開頭 0.05 秒淡入避免爆音；36.59 秒起 1.5 秒淡出。
- 音效一律低於音樂；上表的 dB 是相對值，實作時在成片中量每個點的音效峰值與音樂短時響度，確認差距。
- 成片整體正規化到 −14 LUFS（兩段式 loudnorm，沿用 `audio/sfx.sh` 的作法），true peak −1 dBTP。
